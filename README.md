# Quiz Application

A simple Java GUI-based quiz application developed using Object-Oriented Programming concepts.  
Users can answer multiple-choice questions and view their score at the end.

## Features
- GUI interface using Java Swing
- Score calculation
- Result display

## How to Run
1. Download the ZIP
2. Extract it
3. Open the `.java` files in any Java IDE (like VS Code or IntelliJ)
4. Run `Main.java`
